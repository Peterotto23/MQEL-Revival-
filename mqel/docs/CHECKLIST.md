# Feature Checklist

Status: 2026-10-14. What the server can do, what has been tested and what is missing.

Sources for "missing":
- NotificationType enum reader of the client (0x93bxxx)
- `*Command` types in the client against the `_cmd_*` handlers in `server/account_state.py`
- Service methods from `docs/analysis/api-gameserver.txt`, filtered to names that occur in the final client; without Admin, Dashboard and SleepyGiant

Legend: `[x]` confirmed in-game · `[~]` built, untested in-game · `[ ]` missing

## Done and confirmed in-game

- [x] Chat (XMPP, `server/xmpp_server.py`): rooms, messages, reconnect, chat for all accounts
- [x] Harvest mine: gold arrives, but delayed (the client sends commands bundled)
- [x] Targeted attacks: consumption and 8-hour recharge
- [x] Castle preview when attacking player castles, par-time timer
- [x] Achievements, potions, friends as AccountSummary, countries, test attack (Visit), castle rating

## Built, untested in-game

- [x] Stars on the end screen like `TrophyManager`: treasure room, under the validation time, all mines destroyed (resurrection = 0)
- [~] Chat: presence/away to room participants (needs two players)
- [~] Chat: private messages, behavior without a running chat server
- [~] LastSeenOnline (the UI doesn't display it anywhere)
- [~] CastleRatingFreePrize None on Visit
